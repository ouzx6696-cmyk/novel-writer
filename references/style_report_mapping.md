# 风格报告转译映射表

外部风格能力报告为四层（`report.json` 的 `schema_version` 为 `"5"`）。读完报告后按下表一次落位，逐项登记去向，不维护独立的转接文件。

| 报告层 | 报告字段 | 落位 |
|---|---|---|
| 第〇 作家契约 | positioning | 人格·作家定义 |
| | purpose | 人格·风格基调 + 章纲的"本章交付" |
| | style_marks_synthesis | 人格·风格基调（一句话风格 / 叙述腔调） |
| | enemy_clauses | 人格·红线 |
| 第一 定量层 | 1.1–1.8 指标 | 人格·姿态层（场景表）+ 节奏参照（≤4 项） |
| | 1.9 角色对话风格 | 故事圣经·人物声纹表（原型化口吻，不落原名） |
| | 1.10 世界观与词汇 | 故事圣经（意象类型化，不落原专名） |
| | 1.11 风格标记 | 人格·风格基调 |
| 第二 技法卡层 | 3–6 张技法卡 | 人格·技法卡（选 ≤5 张，标注来源 ID；取舍写进验收状态） |
| 第三 思维层 | 3.1–3.7 | 人格·不变量层（决策句）；只在规划期用的部分留在故事圣经末尾，不每章读 |

## 三条转译纪律

1. **证据引文不进人格**：报告的证据 quote 只用于回验，人格只写行文机制，不复刻原作内容。
2. **定量指标只作节奏参照**，不做每章阈值。
3. **每项能力先回答"它服务哪条读者体验"**，答不出不入库。

完整转译示范与取舍记录表见 `assets/examples/persona_translation_example.md`。
