# 去AI味：写前纪律与写后回看

> 去AI味不是词汇替换，是让人物和场景有眼前的事可办。句式清理只在人物和结构立住后生效。
>
> - **写前**：场景纪律必过，写进章纲的场景块。可选的是技法取向，不可选的是场景纪律。
> - **写后**：自己回看一遍清单，判断哪条是真命中、哪条是误杀。不用脚本，不评分。

---

## 第一部分：场景纪律（开写前必过）

> 每条回答"写的时候要注意什么"。正反例只有一组，用来说明规则方向，不是模板答案。

### 纪律 1：眼前有事

- **规则**：人物每场只办一件眼下的事。不贴"善良""聪明""冷漠"标签，写他在谁面前退让、碰到什么会撒谎。
- **为什么**：没有具体目标的人物只能输出情绪描述和状态汇报，这是AI味的第一来源。
- **正反例**：❌ 他是一个冷漠的人。✅ 他把门关上了。门没锁，但他也没再开。

### 纪律 2：视角细节

- **规则**：细节跟着人物视角走。紧张的人先看出口，等钱的人盯着手机亮不亮，心虚的人记着对方沉默了多久。
- **为什么**：AI倾向用"全景镜头"均匀铺陈环境；真人只看见跟自己处境有关的细节。
- **正反例**：❌ 房间里陈设简朴，墙上有斑驳的痕迹。✅ 他数了数墙上的裂缝。七条。最长那条能伸进去两根手指。

### 纪律 3：对白做事

- **规则**：人物说话在试探、遮掩、说服、拖延或保住面子。可以答非所问、说一半。两人都知道的背景不为读者重念。
- **为什么**：AI写的对话像走流程：问→答→确认→推进。真人在对话中做事但不一定把事说全。
- **正反例**：❌ "你昨天去哪了？""我去见了一个朋友，聊了很久。"✅ 他没抬头。"忙。"

### 纪律 4：设定后置

- **规则**：规则等人物碰到再讲。先让读者看见它怎么被使用，再补名字与来历。人物没碰到它，正文不提前介绍。
- **为什么**：AI喜欢开篇铺世界观。读者不需要提前知道规则——人物踩上去时自然知道疼。
- **正反例**：❌ 灵力分为九阶，每阶又分三个层次……✅ 他攥紧拳头。指甲掐进肉里，但骨头缝里有什么东西松了一下。

### 纪律 5：反乒乓链

- **规则**：300 字内一问一答超过 8 拍是AI信号。在问答之间插入动作拍（倒水、看手机、起身、走动）打断节奏。
- **为什么**：AI对话像面试：问→答→追问→确认。真人说话会停、会走神、会被打断。
- **正反例**：❌ 连续八轮"你确定？""确定。""什么时候？""明天。"✅ 第三轮他站起来倒了杯水。"明天。""这么急？"

### 纪律 6：冷开场

- **规则**：章首用对话或动作顶第一行。禁"时间标记 + 场景状态"式开头（"清晨，阳光洒进……""夜色深沉，……"）。
- **为什么**：章首是检测权重最高的位置之一。状态铺陈开头是最常见的AI模板。
- **正反例**：❌ 清晨的阳光透过窗帘洒进房间，新的一天开始了。✅ 他把手机按掉。第三遍了。

### 纪律 7：硬结尾

- **规则**：章尾停在动作、物件、完整台词或未解决后果上。禁升华、总结、预告、感叹收尾。
- **为什么**：章尾与章首一样权重高。"他不知道的是……""这一夜注定……"是最明显的AI指纹。
- **正反例**：❌ 从这一刻起，他终于明白，真正的勇气不是无所畏惧。✅ 他站起来。膝盖上沾了两片草叶。他拍了一下，没拍掉。算了。

### 纪律 8：拒微闭环

- **规则**：小窗口（约 300 字）内禁止"出现→确认→执行→反馈"四项齐全。人物每场只推进到当前这一步，结果不满分、回执不齐全、证据不排齐，最多保留三项，第四项留给下一场。
- **为什么**：AI在同一窗口内把一件事从发现到验收全部走完，效率太高、太干净，形成典型结构指纹。
- **正反例**：❌ 他收到消息，确认是老王，立刻回了电话，约定明天见面。✅ 手机震了一下。他看了一眼，没回。过了一个小时才打过去。

### 纪律 9：五行卡

> 每场写之前回答以下五个问题。答不出第 3–5 项不开写。

1. 人物此刻只想办成什么？
2. 阻力从谁的即时反应产生？
3. 本场只演到哪一步就停？
4. 哪些结果不解释，让读者自己看？
5. 哪条信息留到下一场，不在本场验收？

### 纪律 10：闲笔有来路

- **规则**：闲笔、岔话、情绪错位、低信息密度段落可以出现，但必须从当前场景或人物关系长出来。删掉它，这一场的某个信息、气氛或关系要受损；毫不受损就是插上去的装饰。
- **为什么**：AI最会写"树荫挪了位置""红灯滑进队尾"式的闲笔——看起来像人味，其实是模板。
- **正反例**：❌ 树荫挪了位置，他看了看时间。✅ 他数了一遍瓶子。少了一瓶。上次明明是六个。

## 第二部分：写后回看（自己过一遍）

> 逐条判断是真命中还是误杀，命中的改不改由虚拟作家决定。没有必须清零的指标。

### T1 信号（出现即回看）

以下句式出现时回看上下文，判断是习惯还是模板：

- "不是A（而）是B"——含全部翻案变形：并非 / 不在于 / 与其说 / 以为是 / 看似实则 / 不重要而是 / 恰恰相反
- "仿佛 / 犹如 / 宛若"比喻
- "让 / 令 / 使"因果句式
- "当……时 / 的时候"从句
- "与此同时"
- 认知动词前置：他感到 / 觉得 / 意识到 / 注意到
- "心中涌起一股……"
- "嘴角勾起一抹……" / "眼中闪过一丝……"

### T2 同段聚集

以下词汇单次出现可保留，同段 2+ 次才回看：

- 一丝、一抹、些许、几分
- 不禁、不由得、不由自主
- 突然、忽然、猛然（同段 ≤2 次可保留）

### 句式节奏

- 连续排比 ≥3 句：回看是否该保留最强一条
- 单句 >40 字：回看是否在动作转折处拆开
- 连续同主语 ≥4 句：回看是否换主语或拆段
- 段落长度连续 3 段一致：回看是否拆出独句段

### 心理外化

- "他感到 / 觉得" → 是否可直接写感知事实
- 情绪词（紧张 / 难过 / 愤怒）→ 是否可换成身体反应（手抖、攥拳、发呆）

### 对话

- 副词标签（"愤怒地说""轻声说道"）→ 是否可用动作或上下文承接
- 连续 ≥8 句纯对话：回看是否该插入动作 / 沉默 / 环境打断

### 结尾

- 升华 / 总结 / 预告 / 感叹收尾 → 回看是否该改为动作句或画面停

### 误杀防护

以下场景不改，即使命中上述信号：

- 角色口头禅和口癖（"就是说""你懂吧"）
- 对话内情绪词——人在对话中会说"我很难过"
- "他说""她问"等基本对话标签
- 角色刻意的排比（演讲、辩论、情绪高点）
- 引用外部文字（书信、屏幕、消息原文）

### 回看清单

- [ ] T1 命中项已逐条判断（保留或改写，想清楚理由）
- [ ] T2 未同段聚集
- [ ] 无连续 3 句以上排比
- [ ] 无升华 / 总结 / 预告结尾
- [ ] 剧情与章纲一致，无擅自新增或删减
