# 卷纲与主线拆纲

> 规划期读，不每章读。卷纲不是给读者看的概要，是给写作循环的定向指令——
> 判据只有一条：**拿着它，能不能直接推出每一章该往哪走。**
> 出场顺序：先拆主线（定几卷、每卷是哪一步），再展开单卷（这卷内部怎么走）。

---

## 一、拆主线：每卷是总主线的子集

总主线是"谁 + 去哪 + 干什么 + 有什么冲突"，写在 `state/story_foundation.md` 的「全书主线」——连它一起还有"终点画面"：故事最后停在什么状态、从起点到终点发生了什么根本性变化。拆卷时每卷都要回头对这条线。每卷是它在某个阶段的**具体化**，不是另起一个故事。

判据：**指着总主线问"没有这卷，主线走得完吗"**——答"走不完"才算一卷。

> 西游记：总主线是"师徒四人去西天取经"，每一难才是单卷。
> 每一难单独看是个事件，意义来自"这是取经路上的一步"，合起来才完成取经。

后果三条：每卷核心冲突不能是独立的子故事；每卷是同一组人在**这一步**干这一步该干的事；所有卷合起来恰好覆盖全程，不重复不遗漏。

## 二、断点法定卷数

不要先定几卷再往里填。**卷边界是某个根本性变化**，找完断点，卷数自然出来：

| 变化类型 | 例子 |
|---|---|
| 信息变化 | 主角发现了以前不知道的关键事实 |
| 关系变化 | 与某方的关系破裂或建立 |
| 状态变化 | 实力、地位、处境的跃升或坠落 |
| 事件变化 | 发生了无法挽回的事 |

**合格断点 vs 不合格**：

| ✅ | ❌ |
|---|---|
| "发现旧案被压"——知道的事变了，目标跟着变 | "主角继续调查"——什么都没变 |
| "保护伞露出真面目"——知道敌人是谁了 | "主角成长"——太虚，什么算成长 |
| "合作者其实是敌人"——阵营变了 | "故事展开"——空词 |

断点数与卷数的参考对应：0 个 → 1 卷（一本做完）；1 个 → 2 卷；2 个 → 3 卷；3 个 → 4 卷；4+ → 5 卷以上。**这张表只用来确认断点数是否合理，不给用户看。**

作者说不出阶段时，用总主线 + 题材推一版提案让他改；作者一次列出 6–8 个阶段时，先合并。

## 三、本卷核心冲突：三条底线

任何一条不过，不进入拆章。

1. **一句话说完**——"谁 + 想做什么 + 被什么阻碍"，不需要"与此同时""另一方面"。一卷可以有支线，主线只能有一根。
2. **对抗力量具体**——必须是具体的角色、势力或处境，不能是"对抗命运""对抗社会"这类虚词。
3. **冲突双方都有不能退让的理由**——追问"角色 A 退了会怎样？角色 B 退了会怎样？"。双方动机具象且互斥才通过；任一方是"天生邪恶""剧情需要"这类无效动机，继续追；双方动机可调和（存在让各退一步的方案），提醒加固。

## 四、冲突阶梯：2–4 层

核心冲突定义"谁对抗谁"，阶梯定义"怎么一步一步对抗"——是一架梯子，每层比前一层更高更险，不是"更难的同一种事"重复。

设计原则：

1. **每层是前一层结果的直接延伸**——过了第一关才触发第二关，不是因为"时间到了该出下一件事"。
2. **每层比前一层更难**——对手更强、代价更大、选择更痛苦。两层难度差不多就合并或删掉。
3. **层间有转折点**——局面发生根本性变化。

转折点判据：**删掉它，后面的故事还能按原路径走吗？** 能走 → 只是普通推进，调高难度或删；不能走 → 才是转折。一卷 2–4 个，太少平铺直叙，太多喘不过气。

```
第1层（入门） 信息受阻            ↓ 转折：发现旧案被压
第2层（升级） 外部施压            ↓ 转折：保护伞露出真面目
第3层（转折） 内部损失，证据断裂   ↓ 转折：主角被迫选择
第4层（终极） 正面交锋
```

## 五、情绪走向：是弧线，不是词

冲突定义"发生什么事"，情绪走向定义"读者从头到尾情绪怎么变"。先自己定，不先问用户，等方案成型一次性给他判断。

| 弧线模式 | 走向 | 适合 |
|---|---|---|
| 先压后爽 | 压抑 → 压抑 → 更压抑 → 提升 → 打脸 | 爽文、升级、复仇、逆袭 |
| 层层逼近 | 紧张 → 紧张↑ → 逼近 → 震惊 → 舒缓 | 悬疑、探案、解谜 |
| 张力开合 | 紧张 → 舒缓 → 紧张↑ → 舒缓 → 高潮 | 成长、试炼、人物驱动 |
| 蓄势爆发 | 压抑蓄势 → 压抑蓄势 → 爆发 → 余韵 | 对抗、战争、竞技 |

拿不准默认"层层逼近"。弧线每一步对应阶梯的一层；**必须有递进**——"压抑→压抑→压抑"只有量变没有质变，中间要有一个转折把情绪推向期待或愤怒。

## 六、信息差与主导驱动力

冲突推着情节走，信息差推着读者走。**卷纲只定起点和终点，不规定中间细节**——中间变化交给章纲。

三种信息持有关系：主角知道而对手不知道 / 对手知道而主角不知道 / 读者知道而主角不知道。

两条底线：**终点信息差不能等于起点**（否则这卷白写）；**终点不能完全平衡**（如果卷末主角什么都知道了，下一卷没有牵引力）。

由起点→终点的方向定本卷主导驱动力与章节节奏：

| 弧线方向 | 驱动力 | 章节节奏 |
|---|---|---|
| 信息逐步向主角揭露 | 悬疑驱动 | 每章留钩子，释放一层新信息 |
| 对手的陷阱逐步浮现 | 威胁驱动 | 安全期越来越短 |
| 主角优势逐步展示 | 目标驱动 | 阶段性成果 → 新阻碍，循环推进 |
| 读者知道而角色不知道 | 关系驱动 | 张力累积到揭穿 |

## 七、卷 N+1：从角色发声推导方向

上一卷定稿后才规划下一卷，方法不是重新套模板，而是**让现有角色说话**——他们有状态、有意图，下一卷写什么由他们推出来。

对每个活跃角色（含对手和重要配角）问四件事：

```text
【处境】卷末落位——和谁在一起、掌握了什么信息、眼下什么局面
【未完成的事】上卷留下的执念/目标/恐惧——什么还没解决
【卷间思考】在卷与卷的间隙里反复在想什么
【现在想做的事】基于当前处境，下卷最可能推动什么
```

**主线从各角色行动方向的交汇点浮现，不是编出来的。** 至少两个角色的"现在想做的事"指向同一个矛盾点，主线就成立了；各走各路没有交汇，要么漏了关键角色，要么主角缺乏明确目标。

从发声到章节：每个角色"现在想做的事"大约占几章，加总即卷长；再从这条主线拆出各阶段的推进方向。主线清晰时，结构模板只是辅助骨架；实在没方向，才回头用模板找结构。

## 八、每章要有可写的冲突载体

章纲的每一行都必须含一个可写的事件冲突。四种不合格：

| 类型 | 典型句式 | 修正 |
|---|---|---|
| 主题式 | "本章讲信任" | 把概念变成具体事件 |
| 功能式 | "建立人物关系" | 把功能折入冲突事件 |
| 梗概式 | "主角经历了冒险" | 指认最核心的一件事 |
| 结果式 | "主角赢了比赛" | 写出阻碍和对抗过程 |

**章节间必须有因果链**：前一章的章末变化，是后一章的起点或动机。指着两章问"为什么第一章之后是第二章、而不是直接跳到第三章"，答不出来就是没有因果链。

## 九、卷纲层面的 AI 味速查

写完后扫一遍，命中就改：

- **空洞的冲突描述**——"展开精彩对决""冲突激烈升级"。速查："精彩""激烈""惊心动魄"。
- **万能推进句式**——"随着调查的深入，真相逐渐浮出水面""在这个过程中，主角遇到了新的挑战"。速查："随着""在这个过程中""与此同时"。
- **预告片式语言**——"更大的阴谋正在酝酿""命运的齿轮开始转动"。追问：谁在做？做了什么？
- **空洞的节奏填充词**——"暗流涌动""波谲云诡"（写了涌动却没写谁和谁在对抗）。速查："暗流""波谲""扑朔迷离"。

## 十、三条快速自检

不用逐条打勾，写完自己问三句：

1. 不看文件，能说出本卷核心冲突一句话吗？
2. 随便指一章，能说出"这章结束后什么东西变了"吗？
3. 随便指两章，能说出为什么第一章之后是第二章，而不是直接跳到第三章吗？

三句都答得出，卷纲可写。答不出，回去补对应那一节。
